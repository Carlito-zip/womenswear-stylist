# Muse — Womenswear Outfit Stylist

A working local-first MVP of a womenswear outfit recommendation website.

## Run locally

1. Install Node.js 18.17+ (Node 20 recommended).
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Included
- Responsive editorial fashion UI
- Garment, color, style, occasion and season selectors
- Rule-based outfit recommendation engine
- Six ranked outfit suggestions
- Local favorites saved in browser localStorage
- No database, API keys or account required

## Production ideas
Add Supabase/Postgres for accounts + wardrobes, image uploads/vision tagging, weather, richer compatibility data and personalized scoring from saves/dislikes.
